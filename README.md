# Hribok — Elite Multi-Game Cheat Framework

Hribok — це потужний та легкий чит-фреймворк для Unity WebGL ігор (veck.io, smashkarts.io, kour.io, narrow.one та інших).

## 🚀 Особливості
- **Aimbot & Combat** — Silent Aim, PSilent, Trigger Bot, Hover to Kill.
- **Visuals & ESP** — Box ESP, Skeleton, Tracers, Chams, Glow.
- **Player Mods** — Bhop, Fly, Speed, God Mode, No Gravity.
- **Skinchanger** — кастомні скіни на зброю, ножі та рукавички.
- **UI & Themes** — 21 таб, понад 300 функцій, анімовані теми (Sakura, Neon, Aurora).
- **Hribok Unique** — Butterfly, Spin Bot, Hribok AI, Cloud Configs.

## 📥 Встановлення
1. Встановіть розширення **Tampermonkey** (або Violentmonkey) для вашого браузера.
2. Натисніть на це посилання, щоб встановити скрипт: **[Install Hribok](https://raw.githubusercontent.com/Hribok/hribok-loader/main/hribok.user.js)**.
3. Зайдіть на сайт гри (наприклад, `veck.io`).
4. Натисніть клавішу **P**, щоб відкрити меню.

## 🛠 Для розробників
- **`hribok.user.js`** — Tampermonkey лоадер.
- **`unitywebmodkit.js`** — ядро для ін'єкції в IL2CPP.
- **`scripts/veck.js`** — головний скрипт для veck.io.
- **`scripts/veck_ui_*.js`** — модулі інтерфейсу (теми, таби, компоненти).

## ⚠️ Важливо
Цей проект створений виключно з освітньою метою (для дослідження WebGL та Unity). Використовуйте на свій страх і ризик.
