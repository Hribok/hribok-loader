## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/)
2. Open [`hribok.user.js`](https://raw.githubusercontent.com/Hribok/hribok-loader/main/hribok.user.js)
3. Tampermonkey will prompt to install — click **Install**
4. Join any supported game — Hribok will load automatically
5. Press **P** to open the menu

## Configs

Hribok comes with 6 preset configs:

| Config | Description |
|--------|-------------|
| **Legit** | Low FOV, smooth aim, no anti-aim |
| **Rage** | Max FOV, instant aim, aggressive |
| **HvH** | Anti-aim, desync, resolver, fake lag |
| **Scout** | Optimized for fast firing |
| **Sniper** | Precision, min damage, auto wall |
| **Custom** | Your own config |
